**Project type:** Team robotics competition project

This project involved the development of a mobile robotic platform capable of completing multiple autonomous competition tasks, including line and wall following, grid solving, object detection, colour detection, and object handling using a mechanical gripper.

The project provided practical experience in robotic system integration, mechanical design, sensor integration, prototyping, and iterative testing.
